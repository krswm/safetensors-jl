# Safetensors Reader for Julia

This library reads tensors from a [Safetensors](https://github.com/safetensors/safetensors) file.

> [!IMPORTANT]
> Currently, this library is intended to be used only by my own projects.
>
> You may probably want to use [SafeTensors.jl](https://github.com/FluxML/SafeTensors.jl) instead.
